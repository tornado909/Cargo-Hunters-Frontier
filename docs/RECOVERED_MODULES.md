# Frontier: восстановленные проекты всех 32 DLL

**Состояние: кандидаты для разработки, НЕ production-замена.**

В каталоге `src/Recovered/` сохранены 32 компилируемых проекта C#, соответствующих 32 DLL установленного `FrontierPack` для Cargo Hunters `0.26.38.59`. Каждый проект имеет собственный `.csproj`, исходники, SHA-256 исходной DLL и SHA-256 каждого файла в `docs/recovered-module-manifest.json`.

## Происхождение и ограничения

Эти 32 проекта получены из проверенных DLL (ILSpy + точечные исправления ошибок декомпиляции), а не из оригинальных авторских исходников. Их статус — *decompiled reference; not original build source*.

**Оригинальные авторские исходники** хранятся отдельно: `src/Engine/`, `src/Reserve/`, `src/Survivor/`, `src/Candidates/SurvivorCoop/` и `history/authored/`. Их происхождение и проверенные контрольные суммы описаны в [AUTHORED_SOURCE_RECOVERY.md](AUTHORED_SOURCE_RECOVERY.md). Когда найден достоверный авторский исходник актуальной версии модуля, именно он должен заменить соответствующего кандидата.

Состояние после локальной проверки:

| Проверка | Результат |
|---|---:|
| Найденные производственные DLL | 32/32 |
| Восстановленные и сохранённые C# проекты | 32/32 |
| Компиляция каждого проекта с version-matched IL2CPP references | 32/32 |
| Совпадение публичных классов и методов, имени и версии сборки | 32/32 |
| Полное побайтное совпадение DLL | 0/32 |
| Игровая приёмка именно этих DLL | Ещё нет |

**Совпадение публичного API не означает совпадение поведения.** В частности, Steam P2P, игровые события, многопользовательские сохранения, ремонт экипировки, загрузка Reserve/Survivor и обработчики Unity IL2CPP необходимо проверять в реальной игре. Ни один восстановленный бинарник не допускается к автоматической замене в стабильных релизах.

## CI

- `scripts/verify-recovered-sources.py`: проверяет 32 проекта, 361 исходный файл и SHA-256 каждого файла, гарантирует отдельный статус восстановления.
- `scripts/stage-recovered-references.py`: загружает в изолированную область CI только ранее проверенные DLL для компиляции, сверяя их с оригинальными SHA-256.
- `src/Tools/ApiSurfaceAudit/`: читает metadata PE/CLI оригинальной и пересобранной DLL, сверяет имя, версию, публичные типы, поля, методы и количество параметров.
- `scripts/build-recovered-modules.py`: компилирует все 32 проекта и проверяет публичный API; составляет локальный диагностический отчёт.
- [Build and audit 32 recovered Frontier DLL candidates](../.github/workflows/build-recovered-modules.yml): **ручной** GitHub Actions workflow; получает зашифрованные референсы версии 0.26.38.59, исполняет проверки, удаляет их после завершения. **Не** публикует тестовые DLL и не изменяет релизный ZIP.

Исходные C# файлы доступны всем; сторонние игровые библиотеки, приватные референсы и токены в Git не добавлены. Снимок DLL привязан к установленной версии игры. Любые новые версии требуют повторной верификации.

## Строгая политика выпуска

Действующий стабильный `v0.1.0` продолжает включать **3 DLL из проверенных авторских исходников** и **32 SHA-256-верифицированных производственных DLL**. Pipeline `build-release.yml` не должен забирать файлы из `src/Recovered/`.

Следующая стадия — согласовать поведение каждого модуля с авторскими исходниками, пройти тесты в игре и только после этого по одному переводить модули с проверенных бинарников на релизную сборку из источников.
