## Важно для работы

- Не собирать производство из устаревшего Survivor 0.1.3, выдавая его за 0.2.0.
- Все версии устанавливаемых DLL проверяются по SHA-256 перед и после игры.
- Для полноценной CI-сборки DLL требуются IL2CPP-интероп библиотеки
  **того же** релиза игры. Они не публикуются в GitHub как исходники.
- Восстановленные Core/Loot кодовые файлы допускаются как справочные материалы;
  все изменения должны сверяться с фактически установленными бинарниками.
- Ветку импорта проверять в PR до объединения с `main`.
- Teammate Flags: отдельный репозиторий `QueenDekim/Cargo-Hunters-Teammate-Flags`.
- Не смешивать игровые сохранения и диагностические архивы с исходниками.
