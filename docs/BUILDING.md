# Сборка Frontier

**GitHub Actions настроен для ZIP с корневой папкой BepInEx.** Подробный регламент: [RELEASE_PIPELINE.md](RELEASE_PIPELINE.md).

## Что собирается автоматически

- src/Plugins/UniversalRepairKit
- src/Plugins/SurvivorWearGuard
- src/Plugins/SurvivorExitGuard

Каждый из этих модулей собран с version-matched референсами, и результат на проверенном build host ранее совпал SHA-256 с установленной DLL.

В Release также входят **32 других проверенных DLL Frontier** из SHA-256-зафиксированного production-снимка. Они **не** пересобираются из исходников в Actions — текущая исходная база неполная. Полная сборка всех модулей запрещена до переноса актуальных production-исходников и игровых испытаний.

## Принципы

- Game-version pin: **0.26.38.59**, несоответствие останавливает Release.
- Не класть game-generated IL2CPP референсы, дампы, сохранения, Steam-данные, артефакты BepInEx и чужие игровые исходники в публичный Git.
- Для сборки разрешены **только GitHub-hosted Actions и изолированное рабочее пространство ASCENTO-PC**. Не использовать ASC-AI или другие вычислительные хосты.
- Не заменять актуальный установленный Survivor 0.2.0 устаревшими src/Survivor исходниками.
- Не подменять production Core или Loot декомпилированными reference-проектами.
- Выдавать именно папку **BepInEx/** внутри ZIP.
- Публиковать SHA256SUMS и BUILD-INFO с честным происхождением каждой DLL.
- Не использовать Actions artifact storage: стабильные ZIP напрямую в Releases, ручной CI dry-run в временный Pre-release (после проверки удалить).

Стабильные изменения требуют ручной приемки в игре, а в мультиплеере — идентичного модпака у каждого игрока.


## Разрешённая среда разработки (обновлено 11.10.2026)

- **GitHub Actions** — проверка источников, CI-компиляция, упаковка тестовых и стабильных релизов.
- **ASCENTO-PC** — локальная компиляция из исходников GitHub с установленным .NET SDK, хранение временных DLL и испытания.
- **Отдельная тестовая игра:** `D:\Games\Cargo Hunters Modded\Frontier-Source\Reserve-Work\Runtime`. У тестовой копии собственные профили Unity и сохранений. Только сюда разрешено временно подставлять экспериментальные DLL с предварительным резервным копированием.
- **Основная установка:** `D:\Games\Cargo Hunters Modded` — исключительно для чтения и сравнения контрольных сумм; менять её только по отдельному прямому поручению пользователя.
- **ASC-AI и другие хосты — не использовать** для Cargo Hunters, включая исходники, компиляцию, временные файлы и передачу сборок.

Локальные артефакты текущей проверки находятся на ASCENTO-PC в рабочем каталоге `%USERPROFILE%\FrontierKitWork\pc-source-build-20261011`. На этом ПК собраны 35 DLL (32 FrontierPack + 3 вспомогательные), все прошли сравнение публичного CLR API и проверку запуска в тестовом экземпляре. Для работы модульных DLL требуется синхронизация SHA-256 в `module.json`; резервную копию нужно восстановить после теста. Полная игровая приёмка (рейды, сохранения, кооператив) пока не проведена.

**Правило выпуска:** успешная компиляция, совпадение публичного API и загрузка до главного меню не доказывают эквивалентность поведения. Не заменять стабильные DLL в GitHub Release экспериментальными до отдельных игровых тестов.
