# Сборка и релизы Cargo Hunters Frontier

**[Скачать последнюю версию](https://github.com/tornado909/Cargo-Hunters-Frontier/releases/latest)** · [GitHub Actions](https://github.com/tornado909/Cargo-Hunters-Frontier/actions/workflows/build-release.yml) · [Описание модпака](../README.md)

## Для игроков

1. Используйте совместимую версию игры (для релиза `v0.1.0` — `0.26.38.59`) и установленный BepInEx IL2CPP.
2. Скачайте `Cargo-Hunters-Frontier-v*.zip` из [Releases](../../releases).
3. Сделайте резервную копию существующего модпака и сохранений.
4. Распакуйте папку `BepInEx` из архива в каталог игры, объединив папки.
5. Перезапустите игру и проверьте загрузку Frontier.

Для сетевой игры наборы и версии модов у участников должны совпадать. Teammate Flags распространяется в отдельном репозитории.

## GitHub Actions

- `validate.yml`: проверки исходников и тестов при PR и обновлении основной ветки.
- `build-release.yml`: сборка и проверка пакета; тег `v*` публикует GitHub Release с установочным ZIP, `BUILD-INFO.json` и `SHA256SUMS.txt`.
- Ручной запуск `build-release.yml`: тестовая сборка через временный Pre-release (без использования квоты Actions artifacts).
- `build-authored-sources.yml` и `build-recovered-modules.yml`: дополнительные проверки исходников; собранные кандидаты не подменяют стабильные DLL.

Для версии `v0.1.0` **три вспомогательных плагина** собираются из проверенных исходников, **32 DLL FrontierPack** включаются из SHA-256-проверенного бинарного снимка. Компилируемые C#-проекты всех 32 модулей есть в `src/Recovered/`, но они не считаются готовой production-заменой до проверки в игре.

CI использует защищённые и привязанные к версии игры сборочные референсы. Они не входят в публичный Git. Публикация новой версии должна проходить проверку целостности архива, контрольных сумм модулей и игровую регрессию.

Подробнее: [RELEASE_PIPELINE.md](RELEASE_PIPELINE.md) · [SOURCE_PROVENANCE.md](SOURCE_PROVENANCE.md).

## Правила публикации

Не включайте в установочный ZIP игровые исполняемые файлы, BepInEx/core, IL2CPP-референсы, пользовательские сохранения, токены или локальные диагностические данные. Обычные пользователи получают только проверенную папку `BepInEx/plugins`.

Компиляция и совпадение публичного API сами по себе не подтверждают полную функциональную совместимость. Стабильные релизы обновляются после проверки загрузки и основных игровых сценариев.
