# Сборки Frontier без нагрузки на игровой ПК

**Основное правило:** ASCENTO-PC используется только для чтения исходников,
проверки совместимости и игровой приёмки; .NET-компилятор на нём не запускается.

## Что уже выполняется на GitHub Actions

Workflow `.github/workflows/validate.yml`:
- контроль отсутствия бинарников, interop-каталогов, дампов и сохранений;
- компиляция и выполнение теста независимого состояния игрока
  `experiments/SurvivorCoop/ProgressCheck`.

Это **не** сборка Frontier.DLL: тесты проверяют только управляемую математическую
модель, без IL2CPP и реального рейда.

## Требование для бинарных сборок

Актуальные проекты `Frontier.Reserve.csproj` и `Frontier.Survivor.csproj`
ссылаются на `$(GameRoot)/BepInEx/interop/*.dll`, BepInEx/core,
а Survivor также на `Frontier.Loot.dll`. Для корректной сборки на
отдельном хосте нужен **точный комплект ссылочных DLL** от той же игры
и FrontierPack. Они не добавляются в GitHub-репозиторий исходников.

Рекомендуемые варианты:
1. Отдельный изолированный build host (например ASC-AI, без GPU-заданий)
   с установленным .NET SDK и контрольным снимком необходимых interop DLL.
2. GitHub Actions с защищённым источником соответствующих референсов,
   доступным только для доверенного workflow и не публикуемым в артефактах.

Не устанавливать self-hosted runner на игровой компьютер. Не сохранять
персональные данные, Steam-токены и пользовательские сохранения в build-кэше.

## Регламент выпуска

1. Исходники и изменения — отдельная ветка и PR.
2. Изолированные тесты и сравнение выходных каталогов — PASS.
3. Сборка необходимых игровых DLL **вне ASCENTO-PC**.
4. Артефакт с версиями, SHA256 и списком изменённых модулей.
5. Тестовая установка с резервным копированием и отдельным сохранением.
6. Обычный хост+гость рейд и проверка идентичности Frontier pack signature.
7. После подтверждения — стабильный релиз с коротким сроком хранения
   временных Actions artifacts (не копить сотни ZIP).

**Блокер:** пока нет проверенного, отдельного от игрового ПК набора
version-matched IL2CPP ссылочных библиотек; полноценные бинарные сборки
в GitHub Actions запускать преждевременно.
